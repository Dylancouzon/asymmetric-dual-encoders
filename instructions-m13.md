Created from M10's remaining work, 2026-09-10. M10 was preparation. This milestone executes the
prepared experiment and measures the frontier; it does not reopen completed recipe families.

## Stages and exit

1. **Make execution ready.** Reuse `m10src` trainer/loader components; implement a dedicated build
   configuration/controller and nano scoring transaction. Rehearse dose/cycle boundaries, resume,
   kill/plateau, budget-capped extensions and access recovery on open/synthetic inputs.
2. **Cloud E.** Measure actual rate and billed price, reserve all downstream costs under $1,000,
   run both E arms under the existing screen registry and compute E1. Keep warmup matched in
   examples; update-count differences remain disclosed. No default from an unread contrast.
3. **Pre-build LoTTE.** Resolve metric, seven slices, identities and skip/veto branch before
   access. The veto can choose bs32 over bs128, so this is before the 200M build. Commit the final
   build configuration and required clean reviews after all recipe choices are fixed.
4. **Build and freeze.** Run the registered dose with monitoring and permitted extensions; retain
   checkpoint, code/config/data hashes, environment, dose, spend and serving-parity evidence.
5. **Final evaluation.** Close `m13/EXECUTION.md`'s defects and ratification gaps; review the real
   executor. M9 closes six-only after recipe decisions are fixed. Both M9/nano emit aligned qids
   and scores for the registered paired row. Evaluate nano under its four conjuncts and fixed
   sequence; execute only the registered conditional reserved batch. Preserve misses and crashes.
6. **Costs.** Measure zero, conventional bge-small and nano under one CPU/serving protocol:
   query/index bytes, hydration, cold/warm p50/p95, peak RSS, thread count and hardware. Dense and
   fused costs stay separate; M12 cloud fusion does not establish Edge fusion latency.

**Done:** documented build outcome, durable quality decisions and comparable costs, sufficient for
release and the paper. A negative result completes the measurement milestone too.
