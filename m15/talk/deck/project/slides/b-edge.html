[~0.5 min] I put all 30,522 rows in a Qdrant Edge shard and fetched them by token ID before pooling and searching. Across 500 queries the vectors exactly matched the released encoder, with a maximum difference of zero. On this laptop the lookup path added about 0.25 ms compared with the in-memory NumPy table.
