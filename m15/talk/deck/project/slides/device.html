[~1.25 min] The area of each box is the size of the encoder files I would ship. I can encode the documents with the big model in the cloud and run the query encoder where the user is. Stella means shipping nearly 1,670 MiB of files. The two smaller boxes are 132 MiB for Nano and 90 MiB for Zero. Zero's int8 table alone accounts for about 31 megabytes of that. These are file sizes. I'd measure resident memory separately. The times come from the CPU on my M5 Pro with four threads, one query at a time. Nano takes a little over two milliseconds. Zero takes 44 microseconds. Compare that with the roughly 32 milliseconds I started with. I can only use those smaller files with my existing index if their query vectors work with Stella's document vectors.
