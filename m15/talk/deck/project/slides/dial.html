[~1.5 min] I call the family Constella. Start with the documents in the middle. Stella encoded them once. Now follow the paths from the query side. I can call Stella, call Nano, a 34.5-million-parameter transformer, or call Zero, the table. The request changes which query vector I produce. All three use the same document vectors, graph, and index. I can try a different encoder on the very next request without re-indexing anything. Imagine I'm building search for a shop. I could use Zero while someone types, give Nano a turn when they pause, and spend the full Stella budget when they hit Enter. That's one policy I'd test. The application already knows which of those events just happened. I can choose the encoder there and send along the search settings that suit it. On a device, that choice also changes what I have to ship.
