[Draft notes; Sol pass pending.] How do you build a cheaper query encoder for an index you already have? Treat the original query encoder as the teacher. Run it once over a large set of texts, keep its normalized vectors, and train a student to land on the same points. The document side is frozen, so anything the student learns is measured against the vectors already in your index. Nano's fit needs no relevance labels; Zero also learns from query and positive-passage pairs. For a new teacher, computing the targets is the main cost: we estimated 8 to 12 hours of encoding for Zero.
