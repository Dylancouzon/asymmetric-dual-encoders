[Draft notes; Sol pass pending.] How do you build a cheaper query encoder for an index you already have? Treat the original query encoder as the teacher. Run it once over a large set of texts, keep its normalized vectors, and train a student to land on the same points. The document side is frozen, so anything the student learns is measured against the vectors already in your index. The vector fit needs no relevance labels. For a new teacher, computing the targets is the main cost: 8 to 12 hours of encoding in our setup.
