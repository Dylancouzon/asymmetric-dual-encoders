[Draft notes; Sol pass pending.] The title says zero compute, so here is the definition in numbers. Stella runs a 24-layer, 1024-wide transformer over 31 tokens: about 25 GFLOPs per query. Nano runs a 12-layer, 384-wide transformer over 12 tokens: about half a GFLOP. Zero gathers one row per token from a table and adds them up: about 28 thousand FLOPs. That is roughly 900,000 times less arithmetic than Stella. No neural network runs when Zero encodes a query; the graph search still runs.
