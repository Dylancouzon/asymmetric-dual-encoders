[~1 min] [Point to the file and peak RSS columns.] If you're trying to fit this on a device, read those as two different bills. Stella has about 435 million parameters in a 1,670 MiB export. It peaks at 2,812 MiB of RAM and takes about two seconds to load with a warm file cache. Nano has 34.5 million parameters and peaks at 317 MiB. On my M5 Pro, the median encode drops from 31.6 to 2.25 milliseconds. Zero is where file size can trip you up. Its 31 MB int8 table holds 31.3 million values. The shipped files also have an fp16 reference table, and the serving loader expands the int8 rows to 125 MB in fp32. The process peaks at 360 MiB, even though the median encode is 44 microseconds. Those are encoder measurements. I can run the big document encoder in the cloud and run the query encoder where the user is.
