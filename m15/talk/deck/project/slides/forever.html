Documents: encoded once

Queries: every search, forever

[~1.5 min] [Let the query line draw.] Follow the line that flattens out. I pay for each document when I index it. Then I get to reuse its vector, the HNSW graph, and the quantized codes on every search. Those assets can last for years. The other line keeps rising because fresh queries keep coming in. An agent can make several searches to finish one task, so I can pay that query cost several times before the user gets an answer. The same asymmetry makes a model migration awkward. If I change the document encoder, I have to go back to the corpus, re-embed it, and rebuild the index. If I need to keep search online, I can end up running both indexes and both ingestion pipelines while I check the new ranking. That's a lot of work to get a cheaper query. What if I could change the query encoder and keep using the index I already serve?
