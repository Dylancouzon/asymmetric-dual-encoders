[~1.75 min] [Trace the layer outputs into the projection.] I started Nano with bge-small. Its last layer gives me fewer features than there are coordinates in Stella's vector. A linear projection can make the output longer. With only that last layer as input, the output can still vary along only as many directions as the input has. I pooled features from earlier layers as well, then joined them before the projection. That gave the projection more directions to work with. I fit the projection first, then trained it along with the backbone. I used Stella's query vectors for query text and its document vectors for passages. That gave me targets without relevance labels. I sampled different ways people ask for things. Some queries read like a title. Others use keywords or ask a full question. I tried the recipe on the desktop.
