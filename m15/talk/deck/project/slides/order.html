[~1.5 min] I can keep every word and still ask for a different ticket. Read "Paris to Rome," then "Rome to Paris." Zero gets the same bag of tokens. The same rows get the same weights, so I get exactly the same vector. Whatever the search does for the first route, it does for the second route too. I wanted to see what the contextual encoders could do with the order. I wrote 24 pairs where reversing the direction changes the answer. Each pair got two passages, one for each direction. To pass, an encoder had to put the intended passage first on both queries. Stella changed its query vector on every reversal. That's an easy test for context to pass. Now watch the ranking test. [click] Stella got both directions right on four of 24 pairs. All four were unit conversions. Nano got two pairs right, and Zero got zero. It's a small exploratory probe. The query and passage pairs are in the repository if you want to try them with another encoder. The exercise gave me two things to check separately. Can the encoder tell the queries apart?
