Tonight’s definition

Zero compute: no neural network encodes the query.

[~0.75 min] By "zero compute" I mean zero neural inference at query time. I still tokenize the text, look up rows, and average them. That work takes microseconds on my laptop. The search starts as soon as I have a vector, and the graph still has to find neighbors for it. I can do the expensive work ahead of time because I know which document vectors I'm going to search. That gives me a target for the table. It also gives me a target for a small transformer, if I want to spend a little more on the query.
