[~1.5 min] [Read the flight query. Point to the row for "cheap".] I run Stella's tokenizer to turn the text into token IDs. Each ID gets me a row from the table. I unpack the stored integer rows when I load the model, so the query can fetch rows that are already in memory. [Follow the single arrow to Zero's vector.] I take a weighted mean of those rows, then normalize the vector. The weight is the square root of the token count. If I type "cheap" again, it gets a little more weight. Each repeat adds less than the one before it. Once I've done that, the vector is ready to search against the same passages.
