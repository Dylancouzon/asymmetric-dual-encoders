[~1.5 min] [Read the flight query. Follow "cheap" to its table row and then to the pooled vector.] Stella's tokenizer gives me an ID for each piece of text. I use that ID to fetch a vector. Those strips are real rows from the released table. When I load the table, I use the stored scales to expand the integer rows into floating-point values. That buys me a short request path at the cost of keeping the expanded rows in memory. At query time I gather those rows, average them with weights, and normalize the result. I weight each row by the square root of its token count. Each extra "cheap" adds less weight than the one before it. That's the whole query computation.
