[~2.0 min] [Follow the highlighted rows from the tokens to the output.] For "cheap flights Paris to Rome," I use Stella's WordPiece tokenizer. Each token ID points at one of 30,522 rows. Each row has 1,024 numbers, so I can combine them directly into a vector with the same dimensions as the documents. If a token repeats, its row gets a weight proportional to the square root of its count. That gives repeats more weight with diminishing returns. I take the weighted mean and normalize it. If you come from Lucene, think of a term-weight lookup that happens to emit a dense query vector. To build the released table, I started the rows from Stella's own token vectors. I trained the pooled output to match Stella's query vectors and used Stella's scores as another target on paired examples. Then I trained the table to rank relevant documents ahead of negatives from the frozen document vectors. I ran that training on a desktop RTX 3080. When I serve the table, I fetch its int8 rows and pool them. The expensive model has already done its part. Look at which information goes into that average.
