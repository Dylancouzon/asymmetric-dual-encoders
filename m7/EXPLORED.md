# M7 avenues explored and closed

Check this before starting anything new.

| avenue | why killed | evidence |
|---|---|---|
| avenue | why killed | evidence |
|---|---|---|
| MIRACL (English) as a training source | Recovering positives for its 2,863 English train queries needs the 32.9M-passage `miracl/miracl-corpus` (no parquet mirror; the HF loader is a removed dataset script). Wikipedia coverage is already supplied by HotpotQA (85K), FEVER (110K), SQuAD (88K) and NQ-open (88K). Cost/benefit fails by two orders of magnitude. | `m7src/trainmix.py` docstring; `datasets` 5.0 refuses `miracl.py` |
| Climate-FEVER in UNTOUCHED-FINAL | No affirmative license at any primary source (climatefever.ai, arXiv:2012.00614 incl. appendices, the GitHub repo has no LICENSE and a silent README). Only HF mirrors claim CC-BY-SA-4.0, and a wrapper tag is not evidence here. | `m7/LEDGER.md` partition ledger; Sonnet primary-source sweep 2026-08-25 |
| fp32 teacher encodes on the dev and training corpora | fp16 is 2.4x faster and indistinguishable: cosine 1.000000 on 10K FiQA docs, \|Δ nDCG@10\| ≤ 3e-4 on both CQADupStack dev components. fp32 is kept for the six-set and untouched-final final run, where the cost is 0.2 h. | `results/m7_throughput.json`, `m7src/dtype_check.py` |
| bare (unprefixed) teacher query vectors as the distillation target | The bge query prefix is worth +1.85 dev macro to the teacher itself (0.5722 prefixed vs 0.5537 bare on the three fast dev components), so the prefixed vector is the better target and the higher retention ceiling. The table's own two prefix variants remain a separate mandated ablation. | `work/devres/refs.json` (`bge-base-symmetric` vs `-nopfx`) |
| a dev component that validates long-query behaviour | The training mix has no long queries: held-out length p50=13 WordPiece tokens, p90=24, and only 55 of 7,325 reach the mandated ≥64. ArguAna's are ~250. The only sources of long argumentative queries are args.me / idebate — ArguAna's own source family, excluded by the contamination map. The ArguAna row is therefore an extrapolation and is labelled as one. | `m7/LEDGER.md` held-out slices section; `work/dev/heldout-longq.json` |
| "no clean untouched-final member is available" | **REOPENED — dismissed too fast.** The 10 unused CQADupStack subforums (android, english, gaming, gis, mathematica, stats, tex, unix, webmasters, wordpress) carry the same ADCS-2015 CC BY-SA evidence as the two already in dev, are non-Wikipedia, and R3 measured cqadupstack TRAIN-positive overlap at ~0 — against 9.32% for DBpedia and 11.3% for FEVER. Adding one or two as untouched-final before the freeze is protocol-compatible (the mandate says "default:") and would materially rescue the partition. A family-level "development-informed" caveat applies and must be labelled. | `results/m7_decontam.json` R3 rows; `m7/LEDGER.md` licence evidence |
| "dev cannot test long-query behaviour at all" | **PARTLY REOPENED.** True for label-dependent metrics, false for teacher-agreement ones: overlap@10 and cosine need no qrels and are already implemented (`stage0_ridge.overlap_at_10`). The mandate pre-authorises shaping synthetic queries to the six's forms "including long counter-arguments", so a few thousand 250-token synthetic queries over approved Wikipedia seeds, scored on teacher agreement, would directly test whether length normalisation degrades at ArguAna lengths — the question the learned-weights ablation needs. Also note the 55-query slice is 54/55 HotpotQA, so it tests long *multi-hop Wikipedia*, not long *argumentative*: n is not its only problem. | `m7/LEDGER.md` long-query section |
| fusing our dense table with `opensearch-neural-sparse-doc-v3-gte` to clear Tier 1 (~0.50 projected) | **DISQUALIFIED, twice.** (1) Hard constraint: no component from a vendor shipping a competing vector-search product — OpenSearch Service is exactly that. (2) Circular: Tier 1 is *defined* as beating opensearch-doc-v3-gte, so a released system containing it satisfies the letter and inverts the spirit. Recorded because a literature sweep proposed it as the top route and it is superficially attractive. | `instructions-m7.md` hard constraints; `research/m7-teacher-shortlist.md` vendor table |
| BM42 as a sparse arm | Already excluded for query-side attention; the exclusion is now **stronger** — independent reproductions (Reimers, Bergum) failed to beat BM25 and Qdrant downgraded it to experimental/not-production. | Qdrant BM42 article + third-party reproduction recaps |
