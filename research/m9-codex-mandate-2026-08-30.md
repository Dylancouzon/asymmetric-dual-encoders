12. **MAJOR — the two-contrast statistic is not fully implementable as written.**  
    “Stratified,” macro weighting, sign-flip tail, dependence construction, permutation count, p-value convention, and CI type are absent. The rule is coherent only after these are fixed. The sign-flip weak-null concern is tolerable only as a conjunct because the bootstrap remains the primary gate.

    **Exact change:** Replace the statistical rule with:

    > For each contrast, align identical qids within each of the six datasets and compute per-query nDCG@10 differences. For each of B=10,000 bootstrap replicates, resample `n_d` queries with replacement independently within dataset `d`, compute each dataset’s mean difference, then average the six dataset means with weight 1/6. The one-sided percentile lower bound is the empirical 0.0125 quantile and must exceed zero. Use one fixed logged bootstrap seed and shared resample indices across C1/C2.  
    > Separately, run B=100,000 one-sided dependent sign-flip replicates on the same equal-dataset statistic. Apply independent Rademacher signs per paired query, using the same sign draws across C1/C2; calculate `p=(1+#(T*≥Tobs))/(B+1)`. Apply Holm step-down to the two raw p-values at family α=0.025. A contrast passes only if its bootstrap bound exceeds zero and Holm rejects it. The sign-flip result is a required sensitivity conjunct, not evidence that its weak-mean-null assumptions hold.
